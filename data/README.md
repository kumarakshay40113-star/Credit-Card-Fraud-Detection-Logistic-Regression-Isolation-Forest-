Place the Kaggle `creditcard.csv` file in this folder if you want to use the benchmark dataset with `train_model.py`.

Download page:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

The CSV is intentionally not bundled because it is a separate large dataset and may require a Kaggle account/acceptance of its terms. The app includes synthetic demo data, so you can run the interface without it.
